# 🧮 BMI Calculator

A simple and user-friendly **BMI Calculator** built using Python.  
The project provides a graphical interface to calculate BMI, classify the result, save records, view BMI history, and visualize BMI trends.

---

## 📌 Project Overview

This project is developed as part of the **Oasis Infobyte Python Development Internship – Task 2**.

The BMI Calculator allows users to:

- Enter their name
- Enter weight in kilograms
- Enter height in meters
- Calculate BMI
- Display BMI category
- Save BMI records in a SQLite database
- View previous BMI records
- Display BMI trend using a graph
- Clear input fields

---

## 🚀 Features

### 1. BMI Calculation

The application calculates BMI using:

```text
BMI = Weight / (Height × Height)
```
